\# Mini juego en Godot

Proyecto realizado como parte de las prácticas de iniciación al desarrollo de videojuegos con Godot.



\## Descripción

Este proyecto contiene una escena de prueba creada en Godot, con una ambientación basada en un castillo.

El objetivo principal es aprender a organizar un proyecto, crear escenas, añadir recursos, utilizar scripts y preparar una primera exportación del juego.
